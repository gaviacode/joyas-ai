# joyas.ai

Proyecto web para joyas.ai: recomendador de joyas con IA y posible monetización mediante afiliación.

## Stack

- Next.js
- React
- TypeScript
- Tailwind CSS

## Reglas de diseño

- Usar responsive design desde el inicio.
- Enfoque mobile-first.
- La web debe funcionar bien en móvil, tablet y PC/escritorio.
- Usar breakpoints de Tailwind para adaptar layouts.
- Mantener estética premium: blanco, dorado, negro y tonos elegantes.
- La IA debe ser protagonista del producto.
- Evitar diseños sobrecargados o baratos.

## Reglas de contenido

- No inventar métricas falsas.
- No inventar clientes satisfechos.
- No inventar reseñas.
- No usar frases como “25.000 clientes” salvo que sean datos reales.
- Priorizar confianza, claridad y elegancia.

## Objetivo inicial

Crear una primera versión de joyas.ai con:

- Home premium.
- Explicación clara del recomendador de joyas con IA.
- Secciones para regalos, anillos, collares, pulseras y joyas para ocasiones especiales.
- Botones preparados para futuros enlaces de afiliado.
- Diseño responsive para móvil, tablet y escritorio.
